# Global Rules

* Always use `git-commit` skill when crafting git commits.
* Prefer granular one-line commits in most cases. When changes are quite inter-dependent and non-trivial to split in granular commits, use multi-line commit message. Never exceed 12 lines total for a commit message.
* Keep code comments minimal: only add a comment when it explains something non-obvious (why, not what). Don't add comments that just restate what the code already says clearly.
